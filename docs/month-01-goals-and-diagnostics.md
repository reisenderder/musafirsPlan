# Цели и стартовая диагностика первого месяца

## Назначение

Первый месяц программы длится с 10 сентября по 9 октября 2026 года. Его главная
цель - не максимальный объем учебного материала, а формирование устойчивой
привычки самостоятельно следовать понятному плану дня.

Школьная программа на этом этапе не учитывается. Собственная программа
создается как основа долгосрочного домашнего обучения; школьные задания можно
будет добавить позднее отдельным направлением.

## Главная цель месяца

К концу месяца ребенок самостоятельно открывает Todoist, понимает очередность
безопасных заданий, начинает и завершает большинство из них без напоминаний,
отмечает результат, фиксирует обычные вопросы знаком `?` и вечером кратко
отчитывается отцу.

## Измеримые показатели самостоятельности

Оцениваются не способности ребенка вообще, а степень помощи, которая требуется
ему для выполнения конкретного действия.

| Показатель | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| Открыл план | Не начал | После нескольких напоминаний | После одного напоминания | Самостоятельно |
| Начал задание | Не начал | Потребовалась постоянная помощь | Потребовалась короткая подсказка | Самостоятельно |
| Следовал инструкции | Не смог продолжить | Делал вместе с отцом | Уточнил один-два пункта | Выполнил самостоятельно |
| Завершил и отметил | Не завершил | Завершил с постоянной помощью | Завершил после напоминания | Завершил и отметил сам |
| Обошелся с затруднением | Бросил или действовал небезопасно | Сразу отвлек отца обычным вопросом | Поставил `?` после подсказки | Сам поставил `?` и перешел дальше |
| Навел порядок | Не убрал | Убрал вместе с отцом | Убрал после напоминания | Сам убрал материалы |
| Дал вечерний отчет | Не смог рассказать | Ответил только на подробные вопросы | Рассказал по коротким вопросам | Сам назвал результат и трудность |

### Целевые ориентиры

- **Конец первой недели:** средний уровень не ниже 1 по каждому показателю.
- **Конец второй недели:** не менее четырех показателей на уровне 2.
- **Конец третьей недели:** не менее четырех показателей на уровне 3, остальные
  не ниже 2.
- **Конец месяца:** уровень 3 по открытию плана, началу задания, отметке
  результата и уборке рабочего места в четырех обычных днях из пяти.

Оценка проводится один раз вечером и занимает не более пяти минут. Единичный
трудный день не считается откатом; важна тенденция за неделю.

## Учебные цели первого месяца

### Математика

- Уточнить фактический уровень первого класса.
- Закреплять счет, сравнение чисел, сложение, вычитание и простые текстовые
  задачи.
- Учиться записывать решение понятно и проверять ответ.

### Русский язык

- Поддерживать уверенное осмысленное чтение.
- Развивать письменную речь, грамотность и умение кратко пересказывать.
- Учиться самостоятельно читать учебную инструкцию и выделять результат.

### Английский язык

- Перейти от знания латинского алфавита к первым словам и простым командам.
- Развивать чтение коротких слов, произношение и понимание базовой лексики.
- Постепенно узнавать английские команды в учебных программах.

### Арабский язык

- Перейти от знания букв к уверенному чтению знакомых сочетаний и слов.
- Связывать небольшое количество знакомых слов с их значением.
- Продолжать повторение выученного из джуза «Амма» без перегрузки.

### Программирование

- Проверить понимание последовательности команд и простых алгоритмов.
- Научиться собирать короткую программу из готовых блоков.
- Объяснять своими словами, что делает созданный алгоритм.

### Технология и инженерия

- Следовать короткой последовательности безопасных действий.
- Создавать простую конструкцию по условию и проверять ее работу.
- Объяснять назначение деталей и предлагать одно улучшение.

## Правила стартовой диагностики

- Диагностика не является экзаменом и не получает школьную отметку.
- Задания распределяются на первые два обычных дня, а не выполняются подряд.
- Один диагностический блок занимает 10-20 минут.
- Отец читает только начальную инструкцию, если это необходимо, и не подсказывает
  ответ.
- Если ребенок не знает ответ, он ставит `?` и переходит к следующему пункту.
- Результат используется только для выбора сложности следующих заданий.

## Диагностические задания

### Математика - 15 минут

1. Запиши числа от 1 до 20, не подсматривая.
2. Реши: `7 + 5`, `14 - 6`, `9 + 8`, `17 - 9`.
3. Поставь знак `>`, `<` или `=`: `8 _ 11`, `14 _ 14`, `16 _ 9`.
4. Реши задачу: «Было 12 деталей. Для модели использовали 5. Сколько деталей
   осталось?»
5. Объясни вслух, как ты проверил один ответ.

Фиксируется количество самостоятельных решений, понимание текста задачи и
способ проверки ответа.

### Русский язык - 15 минут

1. Самостоятельно прочитай небольшой незнакомый текст объемом 100-150 слов.
2. Устно назови главную мысль и три важных события или факта.
3. Напиши четыре-пять предложений о прочитанном.
4. Самостоятельно перечитай написанное и исправь замеченные ошибки.

Фиксируются понимание, связность пересказа, письмо и самопроверка. Конкретный
текст отец подготавливает заранее из имеющейся детской книги без спорного
содержания.

### Английский язык - 10 минут

1. Назови и запиши знакомые латинские буквы.
2. Попробуй прочитать: `cat`, `map`, `pen`, `sit`, `dog`.
3. Соедини команды с действиями: `stand`, `sit`, `open`, `close`, `write`.
4. Назови любые известные английские слова и объясни их значение.

Фиксируются знание букв, связь буквы и звука, знакомая лексика и понимание
простых команд.

### Арабский язык - 15 минут

1. Назови показанные отцом буквы в отдельной и связанной форме.
2. Прочитай пять заранее выбранных знакомых слов с огласовками.
3. Прочитай одну хорошо выученную короткую суру.
4. Назови значение знакомых слов из этой суры, если знаешь.

Фиксируются узнавание букв, соединение, точность чтения и текущий запас
понимаемых слов. Исправление таджвида выполняет отец отдельно после завершения
диагностической попытки.

### Программирование - 15 минут

1. Расположи команды приготовления рабочего места в правильном порядке.
2. Объясни, что произойдет, если поменять местами две команды.
3. В Scratch или ScratchJr собери последовательность: старт, движение, поворот,
   остановка.
4. Запусти ее и объясни результат.

Фиксируются понимание последовательности, причинно-следственная связь и степень
самостоятельности при работе с блоками.

### Технология и инженерия - 20 минут

1. Из безопасного конструктора построй мост между двумя опорами.
2. Проверь, выдерживает ли он заранее выбранный небольшой предмет.
3. Если конструкция не работает, измени ее один раз и проверь повторно.
4. Объясни, какая деталь делает мост устойчивее.

Фиксируются следование условию, проверка результата, реакция на неудачу и
способность объяснить улучшение. Используются только заранее подготовленные
безопасные материалы.

| Направление | Выполнил самостоятельно | Где потребовалась помощь | Что уже умеет | Следующая сложность |
| --- | --- | --- | --- | --- |
| Математика |  |  |  |  |
| Русский |  |  |  |  |
| Английский |  |  |  |  |
| Арабский |  |  |  |  |
| Программирование |  |  |  |  |
| Инженерия |  |  |  |  |

После заполнения таблицы для каждого направления выбирается только один
следующий уровень сложности. Диагностика не повторяется целиком каждый месяц:
дальнейший прогресс определяется по обычным выполненным заданиям и короткой
итоговой работе.
