# ChangeLog

Журнал хранит существенные изменения проекта по датам и направлениям. Записи не
переписываются задним числом: исправления и новые решения добавляются отдельными
пунктами, чтобы сохранялась история развития.

## 2026-09-09

### Управление проектом

- Создан `WORK_PLANS.md` с разделами текущих и завершенных работ.
- Начата работа `WP-001` по базовому плану первого месяца.
- Для изолированной разработки создана ветка `work/base-plan-mvp`.
- Установлено правило: крупное направление разрабатывается в отдельной ветке,
  проверяется и только затем объединяется с основной веткой.

### Горизонт программы

- Долгосрочная программа рассчитана минимум на год и будет развиваться
  последовательными месячными этапами.
- Первый MVP ограничен периодом 10.09.2026–09.10.2026.
- Следующий месяц проектируется после проверки результатов предыдущего.

### Режим дня

- Город для расчета молитвенного времени — Каир.
- День начинается с Фаджра и заканчивается сном после Иша.
- На каждый намаз резервируется 40 минут.
- Учебные, спортивные, бытовые и восстановительные блоки размещаются между
  молитвами.
- Пятница определена как облегченный день; полных выходных на этапе MVP нет.

### Учебная программа

- Основные направления: математика, русский, английский, арабский,
  программирование и инженерные задачи.
- Стартовый уровень математики — первый класс.
- Ребенок уверенно читает по-русски с пониманием и хорошо пишет.
- По арабскому знает буквы и почти выучил джуз «Амма».
- По английскому знаком с латинским алфавитом.
- Для занятий доступен планшет; при необходимости будет подготовлен ноутбук.

### Самостоятельность и контроль

- Ребенок способен самостоятельно читать инструкции в Todoist.
- Отец работает дома и доступен в течение дня, но план должен требовать минимум
  постоянных напоминаний.
- Полный план сначала предоставляется отцу для просмотра.
- Создание или публикация задач в Todoist выполняется только после отдельного
  подтверждения.

### Отложенные направления

- Получение материалов из Telegram.
- Извлечение и переработка пособий из PDF.
- Формальная система проверки материалов на соответствие заданному исламскому
  контексту.

### Цели и диагностика

- Главной целью первого месяца установлено привыкание к самостоятельной работе,
  структуре дня и постепенному развитию без постоянных напоминаний.
- Домашнее обучение определено как долгосрочная основа программы на ближайшие
  5-6 лет; школьная программа временно исключена из MVP.
- Добавлен документ `docs/month-01-goals-and-diagnostics.md`.
- Установлена четырехуровневая шкала самостоятельности и недельные ориентиры.
- Подготовлены стартовые задания по математике, русскому, английскому,
  арабскому, программированию и инженерии.
- Диагностика распределена на два дня и не использует школьные оценки.
